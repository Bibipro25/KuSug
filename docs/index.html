KuSug

原生渲染加速、全菜单 ClickGUI、z1yr 深度集成,一套装齐。

四步装好

无需折腾环境,解压即用

01

下载发布包

前往 GitHub Releases 下载最新版 zip。

02

解压放入

将解压出的全部文件放入客户端资源目录。

03

启用脚本

启动客户端,在脚本列表中启用 KuSug。

04

呼出菜单

进游戏按快捷键呼出主菜单,开始使用。
